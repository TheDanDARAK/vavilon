## Что нового в 0.5.0

### Витрина: каталог игр без покупок

Новая вкладка «🛍 Витрина» рядом с библиотекой — витрина в духе магазина Steam, только смотреть, покупать ничего не нужно:

- **Hero-баннер**: большая обложка с автокаруселью свежих релизов (стрелки, точки-навигация), рейтинг, Metacritic, жанры и дата выхода.
- **Новинки**: релизы за последние 60 дней с фильтрами по жанрам (Экшен, RPG, Шутеры, Стратегии, Гонки и др.).
- **Рекомендуем вам**: подбираются по жанрам вашей библиотеки — теперь с учётом активности (наигранное время важнее количества игр в жанре). Без метаданных в библиотеке — блок «Популярное сейчас».
- **Похожие на ваши игры**: секция с чипсами ваших самых наигранных игр (топ-6); по клику — ряд похожих игр. Сначала пробуется подбор RAWG по «suggested», при недоступности — подбор по жанрам этой игры.
- **⭐ Желаемое**: отмечайте игры на витрине кнопкой «☆ В желаемое» — они складываются в собственный список (сохраняется в `library.json`) и показываются отдельной секцией.
- **Поиск по каталогу**: вся база RAWG (~800 000 игр).
- **Страница игры с витрины**: описание, скриншоты с полноэкранным просмотром, жанры, оценки, «Найти в Steam ↗» и «Официальный сайт ↗».

Игры, уже есть в библиотеке — помечаются бейджем «✓ в библиотеке», отмеченные в желаемое — «⭐ в желаемом».

### Как это работает

- Данные берутся из открытого каталога **RAWG** (бесплатный ключ — вставляется один раз: при первом входе на витрину или в «⚙ Все настройки» → «Витрина»).
- Как и со Steam-метаданными: на диск ничего не пишется — только JSON и ссылки на CDN, картинки стримятся на лету. Ответы API кэшируются в памяти на 10 минут.
- Игры из вишлиста автоматически исключаются из рекомендаций и «похожих», чтобы не дублироваться.

## Полный список изменений

- `main/store.ts` — новый провайдер витрины (RAWG): новинки, популярное, детали, поиск, «suggested»-похожесть с жанровым фолбэком, рекомендации по активности, IPC `store:*`
- `shared/types.ts` — типы `StoreGame / StoreGameDetails / StoreRecommendation / StoreResult / WishlistEntry` + список жанров витрины
- `main/library.ts` — опциональная секция `wishlist` в `library.json` (совместимо со старыми файлами, переживает импорт/замену профиля)
- `StorePage`, `StoreGameDialog` — новые компоненты витрины
- `App.tsx` — вкладки «Библиотека» / «Витрина»
- `SettingsDialog` — поле ключа RAWG
- предпросмотр невалидного ключа/сети — аккуратные состояния ошибок с кнопкой «Повторить»

## Скачивание
