## Что нового в 0.6.0

### Поиск торрентов прямо из карточки игры

В описании игры появилась кнопка **«⬇ Найти раздачу»** — она открывает поиск по названию игры через агрегатор [search.exfreedomist.com](https://search.exfreedomist.com/) и показывает найденные раздачи.

- **Из библиотеки**: откройте описание любой игры — кнопка находится рядом с «Играть» и «Обновить метаданные».
- **С витрины RAWG**: та же кнопка на странице игры в витрине — поиск сразу подставляется название из каталога.
- **Список раздач**: трекер, категория, размер, дата, сиды/личи и отметка «проверено».
- **Сортировка и пагинация**: по популярности, сидам, свежести, размеру или названию; кнопка «Показать ещё 20».
- **Magnet-ссылка**: кнопка получает ссылку, копирует её в буфер обмена и показывает в поле; рядом — «Открыть в клиенте» для передачи в ваш торрент-клиент.

### Как это работает

- Поиск выполняется в главном процессе приложения и не требует API-ключа — только интернет.
- Сайт отдаёт magnet-ссылки через одноразовые страницы с ограниченным временем жизни. Лаунчер запрашивает ссылку лениво, по нажатию, и кеширует её на время открытого диалога. Если ссылка успела устареть — достаточно повторить поиск.
- Ничего о торрентах не сохраняется на диск: между процессами ходят только разобранные данные и сама magnet-ссылка.

## Полный список изменений

- `main/torrents.ts` — новый провайдер поиска: POST-поиск, разбор HTML-выдачи, ленивое получение magnet-ссылки, IPC `torrents:*` (поиск, magnet, копирование, открытие)
- `TorrentSearchDialog` — новый диалог поиска раздач с сортировкой, пагинацией и действиями с magnet
- `GameDetailsDialog` — кнопка «⬇ Найти раздачу»
- `StoreGameDialog` — кнопка «⬇ Найти раздачу» для игр витрины RAWG
- `shared/types.ts` — типы `TorrentResult / TorrentSearchPage / TorrentResultEnvelope`
- `preload/index.ts` — методы `torrentsSearch / torrentsMagnet / torrentsCopy / torrentsOpen`
- `styles.css` — оформление диалога поиска раздач
