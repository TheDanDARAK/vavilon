# Vavilon 0.8.0 — обновления по воздуху, обложки без Steam, больше эмуляторов, Big Picture

## 🔄 Обновления «по воздуху»
- Лаунчер сам проверяет GitHub-релизы при запуске (и раз в 6 часов), показывает баннер
  и прогресс загрузки, а установка запускается кнопкой **«Установить и перезапустить»**.
- Работает через `electron-updater` (NSIS-сборка). Для portable-сборки — резервный путь:
  установщик скачивается с GitHub Releases и запускается.
- Настройка «Проверять обновления при запуске» в разделе «Окно и запуск».
- Релиз публикуется командой `npm run dist -- --publish always` (нужен `GH_TOKEN`) или
  автоматически workflow `.github/workflows/release.yml` по тегу `v*`.

## 🖼 Обложки не только из Steam
- Цепочка источников: **Steam CDN** (600x900 → header → hero) → **SteamGridDB**
  (портретные обложки, встроенный публичный ключ — свой ключ можно указать в настройках) →
  **RAWG** (если указан ключ).
- Обложка качается и тогда, когда у игры нет достижений (например, LEGO Batman 2) — раньше
  падение схемы достижений обрывало загрузку обложки.
- Работает и без AppID: имя игры ищется в Steam и SteamGridDB автоматически.
- В редакторе игры появилась кнопка **«⬇ Обложка из сети»**.

## 🏆 Достижения видны чаще
- Читаются дополнительные папки и форматы эмуляторов, как в Achievement Watcher Next:
  CODEX/RUNE, EMPRESS, RLD!, OnlineFix, CPY, Razor1911 (`.1911`), CreamAPI,
  `%PROGRAMDATA%\Steam`, документы Public/Documents и др. — не только GSE Saves и
  Goldberg SteamEmu Saves.
- Добавлен парсер разблокировок Razor1911 (`achievement`).

## 🛡 gbe_fork и антивирус
- Кнопка **«🛡 Исключение в Защитник»** в окне достижений добавляет папку игры и кэш
  лаунчера в исключения Windows Defender (через `Add-MpPreference`, с подтверждением UAC) —
  это тот же подход, что в Achievement Watcher Next. Ложное срабатывание на эмулятор (`Trojan:Win32/Suschil!rfn`)
  перестаёт мешать.
- По-прежнему можно установить свой `steam_api(64).dll` («📁 Свой DLL»).

## 🎮 Big Picture (геймпад / Sunshine)
- Запуск с флагом **`--bigpicture`**: полноэкранный режим с навигацией геймпадом
  (стик/крестовина — навигация, **A** — запуск, **B** — назад/стоп, **Start** — выход).
- Добавьте в Sunshine отдельное приложение `Vavilon.exe --bigpicture` — удалённо
  поднимается полноэкранный лаунчер, управляемый с джойстика.
