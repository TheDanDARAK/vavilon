# Vavilon

> Игровой комбайн: библиотека игр, постоянные достижения через Steam-эмуляцию и облачные сохранения.

Vavilon — персональный лаунчер для Windows, объединяющий три вещи:

- **Библиотека игр** — добавляй exe-файлы, обложки подтягиваются с Steam CDN, ведётся учёт наигранного времени.
- **Достижения, которые не теряются** — работает через Steam-эмуляцию (gbe_fork/Goldberg): лаунчер ставит эмулятор в один клик, скачивает схему достижений (названия, иконки, редкость — без Steam API-ключа) и хранит историю разблокировок у себя. Удалил игру, переустановил, перенёс на другой ПК — прогресс возвращается одной кнопкой.
- **Облачные сохранения** — встроенный [ludusavi](https://ludusavi.com) знает, где у 19 000+ игр лежат сейвы. Перед запуском сейвы восстанавливаются из облака, после выхода — бэкапятся в папку (например, в Google Drive).

## Возможности

| | |
|---|---|
| 🎮 Библиотека | Обложки по AppID, сортировка, наигранное время, бейдж «запущена» |
| 🖼 Обложки | Steam CDN → SteamGridDB → RAWG; работают и без достижений/AppID |
| 🏆 Достижения | Схема и иконки с Steam CDN, редкость в %, русские названия |
| 💾 Вечный прогресс | Экспорт/импорт профиля в один .json; кнопка «Загрузить прогресс в эмулятор» |
| ☁️ Сохранения | ludusavi wrap: restore перед запуском → игра → backup после выхода |
| 🔔 Попапы | Всплывашки в лаунчере + системные уведомления Windows |
| 📌 Трей | Скрытие в трей, автозапуск с Windows — уведомления работают всегда |
| 🎮 Big Picture | Полноэкранный режим с управлением геймпадом (флаг `--bigpicture`) для Sunshine |
| 🔄 Обновления | Проверка GitHub-релизов при запуске, загрузка и установка прямо из лаунчера |

## Сборка из исходников

Нужен только [Node.js](https://nodejs.org) 20+.

```bash
npm install
npm run dist     # установщик NSIS + portable в папку release/
```

Для разработки:

```bash
npm run dev
```

Проверки перед коммитом:

```bash
npm run typecheck   # TypeScript (main + renderer)
npm test            # unit-тесты парсеров схем достижений и runtime-сейвов
npm run build       # production-сборка
```

## Как это работает

- **Эмулятор достижений** — [gbe_fork](https://github.com/Detanup01/gbe_fork) (GPL-3.0), скачивается с GitHub-релизов при настройке игры, оригинальная `steam_api.dll` сохраняется как `.valve.bak`.
- **Сохранения** — [ludusavi](https://github.com/mtkennerly/ludusavi) (MIT), поставляется в комплекте (`resources/binaries/ludusavi.exe`), конфиг лаунчера изолирован в `%APPDATA%\vavilon\ludusavi-config`.
- **Схема достижений** — парсинг публичных страниц `steamcommunity.com` (ключ Steam API не нужен).

Данные лаунчера: `%APPDATA%\vavilon\` (библиотека `library.json`, настройки `settings.json`, кэш обложек и иконок, ежедневные копии библиотеки в `backups/`).

## Настройка достижений (v0.3)

Работа с эмуляцией разделена на три отдельные операции — по модели
[Achievement Watcher Next](https://github.com/Shirowwww/Achievement-Watcher-Next):

| Операция | Что делает |
|---|---|
| ⚙ **Схема и обложка** | Только конфиг-файлы: схема достижений, иконки, `steam_appid.txt`, обложка с Steam CDN. DLL игры не трогается — не может вызвать срабатывание антивируса |
| 🛠 **Установить эмулятор** | Единственная операция, заменяющая `steam_api.dll` (с бэкапом `.valve.bak` и откатом при ошибке). Подтверждается вручную |
| 📁 **Свой DLL** | Использовать свой `steam_api(64).dll` — тогда лаунчер вообще ничего не скачивает |

При установке также генерируется `steam_settings/steam_interfaces.txt` из оригинальной
DLL игры (сканированием байтов, без запуска сторонних exe). Архив эмулятора скачивается
в память (никогда не пишется на диск), распаковка — встроенным 7-Zip (WebAssembly),
из архива извлекаются только DLL эмулятора. Верификация SHA-256 по дайджесту GitHub.

Плюс: откат эмуляции (восстановление `.valve.bak`, эмуляторный DLL откладывается в
`*.emu-removed.bak`), сброс счётчика достижений (аналог Reset в AW Next), строка
диагностики состояния эмуляции в диалоге достижений.

**Антивирус**: Steam-эмуляторы — известный источник ложных срабатываний
(`Trojan:Win32/Suschil!rfn`). В окне достижений есть кнопка **«🛡 Исключение в Защитник»** —
она добавляет папку игры и кэш лаунчера в исключения Windows Defender (с подтверждением UAC).
Это тот же подход, что в [Achievement Watcher Next](https://github.com/Shirowwww/Achievement-Watcher-Next).
Альтернатива — «📁 Свой DLL» (никаких скачиваний вообще).

## Обложки (v0.8)

Обложка подбирается по цепочке и кэшируется в `userData/covers`:

1. **Steam CDN** — `library_600x900` → `header` → `library_hero` (два зеркала).
2. **SteamGridDB** — портретные обложки сообщества. Используется встроенный публичный ключ,
   поэтому дополнительный ключ не обязателен; свой можно вписать в настройках витрины.
3. **RAWG** — `background_image` по названию (если указан ключ RAWG).

Цепочка работает и когда у игры нет достижений в Steam, и когда не указан AppID
(имя ищется автоматически). В редакторе игры есть кнопка **«⬇ Обложка из сети»**.

## Достижения: какие эмуляторы читаются (v0.8)

Помимо `%APPDATA%\GSE Saves` и `%APPDATA%\Goldberg SteamEmu Saves`, лаунчер читает файлы
разблокировок ещё у ряда scene-эмуляторов (список повторяет таблицу
[Achievement Watcher Next](https://github.com/Shirowwww/Achievement-Watcher-Next)):
CODEX/RUNE, EMPRESS, RLD!, OnlineFix, CPY, Razor1911 (`.1911`), CreamAPI,
`%PROGRAMDATA%\Steam`, а также портативные деревья в `Public\Documents`. Поддержаны форматы
JSON, INI и текстовый `achievement` (Razor1911). Список можно расширять.

## Big Picture и Sunshine (v0.8)

Запустите лаунчер с флагом `--bigpicture` — откроется полноэкранный режим с навигацией
геймпадом (стик или крестовина — перемещение, **A** — запуск, **B** — назад/стоп,
**Start** — выход; клавиатура тоже работает).

Чтобы играть удалённо через **Sunshine**:

1. В веб-интерфейсе Sunshine добавьте новое приложение.
2. Name: `Vavilon Big Picture`.
3. Command: `"C:\Path\To\Vavilon.exe" --bigpicture`.
4. Запустите это приложение со стримингового клиента — лаунчер поднимется на весь экран
   и будет управляться с джойстика.
